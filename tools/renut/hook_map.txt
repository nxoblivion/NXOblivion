# (all non-state hooks; the Set/GetRenderStateHook<> and Set/GetSamplerStateHook<> tables are paired elsewhere).
# Oblivion side: generated/default asm, tools/image.bin, out/renut/d3d_api.txt, out/build/local-release/d3d_trace.txt.
#
# Format: <handler> <katamari sub> <oblivion sub | -> <confidence> <evidence; arg-convention vs reNut handler; notes>
# Confidence: high = shape + fields + callers agree; medium = shape agrees, one detail unverified or args differ;
#   low = best candidate only; none = no Oblivion function found (the API is absent in 2417, or it is inlined).
# "(unhooked)" = katamari declares it with BANJO_RENUT_UNHOOKED_HOOK[_SHARED]; "RAW" = BANJO_RENUT_HOOK_RAW.
# Device offsets below are Oblivion's, in decimal (hex in field_pairs.txt).
# ReXGlue: a tail-branch thunk (b sub_X) becomes a call, so hooking sub_X also covers the thunk.
